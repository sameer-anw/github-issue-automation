# GitHub Issue Automation using Power Automate

## 📌 Project Overview

This project automates issue tracking in GitHub using Microsoft Power Automate.

## ⚙️ Features

* Detects new issues in repository
* Filters bug-related issues
* Sends email notifications
* Improves team productivity

## 🛠 Tools Used

* GitHub
* Microsoft Power Automate
* Outlook / Teams

## 🚀 Workflow

1. New issue created in GitHub
2. Power Automate triggers flow
3. Checks if issue contains "bug"
4. Sends notification
